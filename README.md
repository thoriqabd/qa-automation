# QA Automation Project – Playwright + TypeScript

This repository contains automated end-to-end tests using [Playwright](https://playwright.dev/) with TypeScript.

## 📦 Tech Stack
- Playwright
- TypeScript
- Node.js

## 🚀 Getting Started

### 1. Clone repo & install dependencies
```bash
git clone https://github.com/varnionjgj/vlepo-backend-automation-test.git
cd vlepo-backend-automation-test
npm install

### 2. Setup dotenv
- BASE_URL=https://example.com
- USERNAME=testuser
- PASSWORD=secret123

### 3. Setup .gitignore
- node_modules/
- test-results/
- .env
